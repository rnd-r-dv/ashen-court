# Ashen Court (TCG) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "Ashen Court", a Hearthstone-style dark-fantasy trading card game with 12 curated 60-card archetype decks, a card forge for custom cards (palette effects + image upload), a deck builder, and three play modes (bot with 3 difficulties, hotseat, LAN) — all sharing one deterministic, event-driven rules engine.

**Architecture:** A TypeScript monorepo with three layers: `core/` (framework-free, DOM-free rules engine: intents → validated → resolved as a deterministic queue of events; `submit()` and `applyEvent()` share one mutation path, so bot/hotseat/LAN/UI rendering all use identical state transitions), `server/` (tiny Node `ws` WebSocket server, authoritative rooms with 4-letter codes), and `app/` (React + Vite frontend; `useMatch` hook abstracts the driver so local and LAN play are the same UI code). Procedural SVG/canvas card art renders from `ArtRecipe` data — zero external assets. Tests are Vitest, TDD throughout.

**Tech Stack:** TypeScript, React 18, Vite, Framer Motion, Vitest, Node + `ws` (WebSocket), localStorage (custom cards/decks), plain CSS with custom properties.

## Global Constraints

(Every task's requirements implicitly include this section — values verbatim from the spec `docs/superpowers/specs/2026-08-06-tcg-design.md`.)

- TypeScript everywhere; `core/` MUST have zero DOM and zero Node dependencies (runs in tests, bot, server, browser identically).
- Mana: start 1 crystal, +1 each turn, **cap 15**.
- Decks: exactly 60 cards; up to 3 copies of a card; **rarity copy limits override**: common ×3, rare ×2, epic/legendary ×1 per deck.
- Heroes: 30 HP. Hero power: 2 mana, once per turn. Second player starts with one 0-cost "Mana Surge" spell (effect: `refillMana(1)`), usable once.
- Opening hand: 3 cards, one-time mulligan (keep any subset, redraw the rest). No fatigue — empty deck means draw nothing.
- Win: opponent hero at 0 HP; simultaneous deaths = mutual destruction (winner `'draw'`).
- Keywords: `taunt`, `rush`, `charge`, `windfury`, `lifesteal`, `ward`, `shield`. Triggers: `battlecry`, `deathrattle`, `startOfTurn`, `endOfTurn`, `onDamage`.
- Board limit: **7 creatures per player** (play/summon beyond cap is illegal for intents, skipped for triggers).
- Effect kinds: `dealDamage`, `draw`, `heal`, `buff`, `summon` (value = token count), `gainMana` (empty crystal), `refillMana` (filled), `freeze`, `destroy`, `copyCard` (no cardId = copy random enemy creature), `giveKeyword`, `discountCheapest`, `discountNextSpell`. Cards may have multiple effects (`Card.effects: EffectSpec[]`, applied in order).
- Deterministic: all randomness from one seeded RNG; same seed + same intents = identical game (replayable).
- Custom cards: palette-only (same keyword/effect library), validated by the SAME validator the engine uses; saved to localStorage; JSON export/import.
- LAN: server-authoritative rooms; clients send intents only; 4-letter room codes; reconnect grace 5 minutes.
- Testing: Vitest. Every keyword, effect, phase rule, bot policy, validator rule, and LAN message round-trip has tests.

```ts
export type Rng = () => number;
export function createRng(seed: number): Rng {
  let a = seed >>> 0;
  return () => {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
export function pickRandom<T>(rng: Rng, arr: readonly T[]): T {
  return arr[Math.floor(rng() * arr.length)] as T;
}
export function shuffle<T>(rng: Rng, arr: T[]): T[] {
  const out = [...arr];
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [out[i], out[j]] = [out[j], out[i]];
  }
  return out;
}
```

```ts
import type { Card, Keyword, Rarity } from './types.js';

export const RARITY_COPY_LIMIT: Record<Rarity, number> = { common: 3, rare: 2, epic: 1, legendary: 1 };

/** Budget = attack + health for a vanilla creature at a given cost. */
export function statBudget(cost: number): number { return 2 + 2 * cost; }

export const KEYWORD_COST: Record<Keyword, number> = {
  taunt: 1, rush: 1, charge: 2, windfury: 2, lifesteal: 1, ward: 1, shield: 1,
};

const CREATURE_ONLY_KEYWORDS: Keyword[] = ['taunt', 'rush', 'charge', 'windfury', 'lifesteal', 'ward', 'shield'];
const CREATURE_ONLY_TRIGGERS = ['battlecry', 'deathrattle', 'onDamage'];

export function validateCard(card: Card): ValidationIssue[] {
  const issues: ValidationIssue[] = [];
  const err = (field: string, message: string) => issues.push({ field, message, severity: 'error' });
  const warn = (field: string, message: string) => issues.push({ field, message, severity: 'warning' });

  if (!card.name.trim()) err('name', 'Name is required.');
  if (!/^[a-z0-9-]{3,32}$/.test(card.id)) err('id', 'ID must be lowercase letters, digits, dashes (3-32 chars).');
  if (!Number.isInteger(card.cost) || card.cost < 0 || card.cost > 15) err('cost', 'Cost must be an integer 0..15.');
  if (card.type === 'creature') {
    if (!Number.isInteger(card.attack) || card.attack < 0) err('attack', 'Creature needs attack >= 0.');
    if (!Number.isInteger(card.health) || card.health < 1) err('health', 'Creature needs health >= 1.');
  } else if (card.attack !== undefined || card.health !== undefined) {
    err('type', 'Only creatures have attack/health.');
  }
  for (const tg of card.triggers ?? []) {
    if (tg.when === 'battlecry' && card.type !== 'creature') err('trigger', 'Battlecry is creature-only.');
    if (tg.when === 'onDamage' && card.type !== 'creature') err('trigger', 'OnDamage is creature-only.');
    if (tg.effects.length === 0) err('effect', `Trigger ${tg.when} requires at least one effect.`);
  }
  if (card.type === 'spell' && (card.triggers ?? []).length > 0) err('trigger', 'Spells cannot have triggers.');
  if (card.type === 'spell' && (card.effects ?? []).length === 0) err('effect', 'Spells require at least one effect.');
  if (card.type !== 'spell' && (card.effects ?? []).length > 0) err('effect', 'Only spells use top-level effects; creatures/artifacts use triggers.');
  for (const k of card.keywords) {
    if (k === 'ward' && card.keywords.includes('taunt')) err('keywords', 'Ward and Taunt cannot combine.');
    if (card.type !== 'creature' && CREATURE_ONLY_KEYWORDS.includes(k)) err('keywords', `${k} is creature-only.`);
  }
  if (card.type === 'creature' && card.attack !== undefined && card.health !== undefined) {
    const budget = statBudget(card.cost);
    const spent = card.attack + card.health + card.keywords.reduce((s, k) => s + KEYWORD_COST[k], 0);
    if (spent > budget + 4) err('stats', `Stat+keyword budget ${budget} exceeded by ${spent - budget}.`);
  }
  const TARGET_KINDS: EffectKind[] = ['dealDamage', 'heal', 'buff', 'freeze', 'destroy', 'giveKeyword'];
  const allEffects = [...(card.effects ?? []), ...(card.triggers ?? []).flatMap(t => t.effects)];
  for (const e of allEffects) {
    if (TARGET_KINDS.includes(e.kind) && !e.target) err('effect', `${e.kind} requires a target.`);
  }
  return issues;
}

export function validateDeck(cardIds: string[], pool: Map<string, Card>): ValidationIssue[] {
  const issues: ValidationIssue[] = [];
  const counts = new Map<string, number>();
  for (const id of cardIds) {
    const card = pool.get(id);
    if (!card) { issues.push({ field: 'deck', message: `Unknown card id: ${id}`, severity: 'error' }); continue; }
    const n = (counts.get(id) ?? 0) + 1;
    counts.set(id, n);
    if (n > RARITY_COPY_LIMIT[card.rarity]) issues.push({ field: 'deck', message: `More than ${RARITY_COPY_LIMIT[card.rarity]} copies of ${card.name} (${card.rarity}).`, severity: 'error' });
  }
  if (cardIds.length !== 60) issues.push({ field: 'deck', message: `Deck must be exactly 60 cards (has ${cardIds.length}).`, severity: 'error' });
  return issues;
}
```

```ts
export class Game {
  state: GameState;
  private rng: Rng;
  constructor(setup: MatchSetup, registry: CardRegistry) {
    if (!setup.heroes || setup.heroes.length !== 2) throw new Error('Two heroes required');
    // validate both decks against the registry
    for (const [i, deck] of setup.decks.entries()) {
      const issues = validateDeck(deck, registry.pool());
      if (issues.some(i => i.severity === 'error')) throw new Error(`Deck ${i} invalid: ${issues.map(i => i.message).join('; ')}`);
    }
    this.rng = createRng(setup.seed);
    const players: [PlayerState, PlayerState] = [
      this.makePlayer(0, setup, registry),
      this.makePlayer(1, setup, registry),
    ];
    // deal starting hands
    for (const p of players) for (let i = 0; i < STARTING_HAND; i++) p.hand.push(p.deck.pop()!);
    // player 1 gets Mana Surge
    players[1].hand.push(MANA_SURGE);
    players[1].surged = true;
    this.state = { players, turn: 0, phase: 'mulligan', seed: setup.seed, log: [] };
  }
  // ... makePlayer shuffles deck with this.rng, fills hero state, mana 0/0
  currentPlayer(): PlayerIndex { return (this.state.turn % 2) as PlayerIndex; }

  submit(intent: Intent): GameEvent[] {
    const events: GameEvent[] = [];
    const me = this.currentPlayer();
    if (intent.kind === 'mulligan') {
      if (this.state.phase !== 'mulligan') throw new Error('Not in mulligan');
      const p = this.state.players[me];
      // keep set must be valid indices
      const kept = [...intent.keep].sort((a, b) => b - a);
      for (const idx of kept) { if (idx < 0 || idx >= p.hand.length) throw new Error('Bad keep index'); }
      const keptCards = intent.keep.map(i => p.hand[i]);
      for (const idx of kept) p.hand.splice(idx, 1);
      p.hand = [...keptCards];
      while (p.hand.length < STARTING_HAND && p.deck.length > 0) {
        const cardId = p.deck.pop()!; p.hand.push(cardId);
        events.push({ type: 'cardDrawn', player: me, cardId });
      }
      this.mulligansDone.add(me);
      if (this.mulligansDone.size === 2) this.startMain();
      return events;
    }
    if (intent.kind === 'endTurn') { ... return this.endTurn(me); }
    throw new Error('Intent not implemented yet');   // replaced in Tasks 9-11
  }
}
```

## Phase 2 — Card Pool + 12 Curated Decks

> **Amendments to Phase 1 interfaces (apply when implementing Phase 1; supersede the descriptions above):**
>
> 1. **Multi-effect cards**: `Card.effects: EffectSpec[]` REPLACES `Card.effect`. `types.ts` uses `effects: EffectSpec[]` (spells-only: cast effects). `validate.ts` (Task 3): trigger groups require `effects.length > 0`; tests use `effects: [{...}]`. Play resolution (Task 9), battlecry/deathrattle/onDamage (Task 8), and artifacts (Task 8) apply **each** spec in array order. `HeroPower.effects` already is an array — unchanged.
> 2. **Summon counts**: effect `summon` with `value > 1` summons N tokens of `cardId`.
> 3. **copyCard without cardId**: copies a random enemy creature's card (its `cardId`) to the controller's hand (seeded RNG pick).
> 4. **Board cap**: max 7 creatures per player. `playCard` (creature) intent is illegal at cap; trigger summons (deathrattle/startOfTurn/etc.) that would exceed the cap are **skipped** (emit `effectResolved` only).
> 5. **RNG access**: `Game` exposes `random(): number` and `pickRandom<T>(arr: readonly T[]): T` — one seeded stream shared by effects, bots, and anything random (keeps replays deterministic). Bots get no own RNG.
> 6. **Mana Surge is a real card**: the pool includes `mana-surge` (0-cost spell, `effects: [{ kind: 'refillMana', value: 1 }]`, archetype `'token'`) so the app can render it; the engine still injects it into player 1's hand at setup.
> 7. Tokens have `archetype: 'token'`; `CardRegistry.tokens()` returns them; they are NOT valid deck members (validateDeck rejects `archetype === 'token'`).
> 8. **Art assignment**: every curated card's `ArtRecipe` uses its archetype's canonical preset (e.g. all `ember-*` cards use the `ember` preset), `palette` from the preset, `seed` = deterministic hash of the card id (stable across reloads; distinct per card). Card tables omit the `art` column — derive it, don't invent presets.
> 9. **Multi-trigger cards**: `Card.trigger?: Trigger` is REPLACED by `Card.triggers?: TriggerSpec[]` where `TriggerSpec = { when: Trigger; effects: EffectSpec[] }`. Battlecry/deathrattle/startOfTurn/endOfTurn/onDamage effects live in groups; top-level `card.effects` is **spells-only** (cast effects). Tables encode groups with `WHEN: effects` prefixes separated by `;` (e.g. phoenix `BC: dmg3(ae); DR: summon(token-phoenixash)`); a bare trigger code in the KW/Trg column + the Effects column = one group. Spells cannot have `triggers`; creatures/artifacts cannot have top-level `effects`.

```ts
export function evaluate(game: Game, me: PlayerIndex): number {
  const { players } = game.state;
  const meP = players[me], foeP = players[1 - me];
  const board = (p: PlayerState) => p.board.reduce((s, c) => s
```

```ts
chooseIntent(game, me) {
  const start = performance.now();
  let best = { intent: game.legalIntents(me)[0], score: -Infinity };
  for (const intent of game.legalIntents(me)) {
    const g = game.clone(); g.submit(intent);
    let score = evaluate(g, me);
    if (performance.now() - start > 1000) break;

    const enemyGreedy = bestReply(g, 1 - me);
    if (enemyGreedy) { const g2 = g.clone(); g2.submit(enemyGreedy); score = evaluate(g2, me); }
    if (score > best.score) best = { intent, score };
  }
  return best.intent;
}
```
